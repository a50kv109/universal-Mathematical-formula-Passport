# PTH-005 — Высота и проекции катетов на гипотенузу (`PYTHAGOREAN FAMILY`)

- **ID:** `PTH-005`
- **Название:** Метрические соотношения в прямоугольном треугольнике через проекции на гипотенузу
- **Категория:** `Mathematical Relations`
- **Статус достоверности:** `DERIVED` — классическое следствие подобия прямоугольных треугольников, дающее прямой алгебраический вывод `PTH-001`

---

## 1. ID и название

`PTH-005` — разложение квадрата гипотенузы и квадратов катетов через ортогональные проекции $p, q$ катетов на гипотенузу (теорема о среднем геометрическом / доказательство Евклида через подобие).

---

## 2. Исходная математическая идея

Высота $h$, опущенная из прямого угла на гипотенузу $c$, делит исходный прямоугольный треугольник на два меньших прямоугольных треугольника, подобных ему и друг другу. Из подобия сразу следует, что каждый катет является средним геометрическим между всей гипотенузой и своей проекцией на неё, а сумма этих двух равенств воспроизводит $a^2 + b^2 = c^2$.

---

## 3. Формулы

$$a^2 = c p, \qquad b^2 = c q, \qquad p + q = c$$

Дополнительно для высоты $h$ к гипотенузе:

$$h^2 = p q$$

Сложение первых двух соотношений:

$$a^2 + b^2 = c p + c q = c(p + q) = c^2$$

---

## 4. Геометрическая или алгебраическая интерпретация

- **Объект:** прямоугольный треугольник $\triangle ABC$ ($\angle C = 90^\circ$) с катетами $a, b$, гипотенузой $c$ и высотой $h = CD$ к гипотенузе.
- **Проекции:** основание высоты $D$ делит гипотенузу $c$ на два отрезка длины $p$ (проекция катета $a$) и $q$ (проекция катета $b$), причём $p + q = c$.
- **Геометрический смысл:** площадь квадрата $a^2$ равна площади прямоугольника $c \times p$, а площадь квадрата $b^2$ равна площади прямоугольника $c \times q$ (именно так устроена диаграмма в I.47 «Начал» Евклида).

---

## 5. Доказательство либо ссылка на обоснование

1. Высота $h$ к гипотенузе образует два прямоугольных треугольника с общими острыми углами исходного треугольника, следовательно все три прямоугольных треугольника подобны.
2. Из подобия треугольника при катете $a$ и исходного треугольника:
   $$\frac{a}{c} = \frac{p}{a} \implies a^2 = c p$$
3. Из подобия треугольника при катете $b$ и исходного треугольника:
   $$\frac{b}{c} = \frac{q}{b} \implies b^2 = c q$$
4. Из подобия двух меньших треугольников между собой:
   $$\frac{h}{p} = \frac{q}{h} \implies h^2 = p q$$
5. Суммируя и учитывая $p + q = c$:
   $$a^2 + b^2 = c(p + q) = c^2$$

---

## 6. Условия применимости

- Треугольник **невырожденный прямоугольный** в евклидовой плоскости ($a > 0, b > 0, c > 0$).
- Обозначения проекций зафиксированы однозначно: $p$ — ортогональная проекция именно катета $a$ на гипотенузу $c$ (примыкает к вершине при катете $a$), $q$ — ортогональная проекция именно катета $b$ на гипотенузу $c$ (примыкает к вершине при катете $b$), с $p > 0, q > 0, p + q = c$. (Перестановка $p \leftrightarrow q$ без перестановки $a \leftrightarrow b$ делает формулы $a^2 = cp$ и $b^2 = cq$ неверными при $a \neq b$.)

---

## 7. Примеры

Для треугольника **$3\text{–}4\text{–}5$** ($a = 3, b = 4, c = 5$):

- $p = \frac{a^2}{c} = \frac{9}{5} = 1.8$
- $q = \frac{b^2}{c} = \frac{16}{5} = 3.2$
- Проверка разбиения гипотенузы: $p + q = 1.8 + 3.2 = 5.0 = c$ (**PASS**)
- Проверка катетов: $c p = 5 \cdot 1.8 = 9 = 3^2$, $c q = 5 \cdot 3.2 = 16 = 4^2$ (**PASS**)
- Высота к гипотенузе: $h^2 = p q = 1.8 \cdot 3.2 = 5.76 \implies h = 2.4 = \frac{ab}{c}$ (**PASS**)

---

## 8. Известные ограничения

- В **тупоугольном** треугольнике высота на продолжение стороны даёт проекции, не удовлетворяющие $p + q = c$ с положительными знаками, а равенства $a^2 = cp$ и $b^2 = cq$ неверны без прямого угла при противоположной вершине.
- Записи `a^2 = c * p` и `b^2 = c * q` вне треугольника являются обычными алгебраическими квадратичными зависимостями (например, кинематика или пропорция $c/a = a/p$).

---

## 9. Статус проверки и связи

- **Mathematical Verification:** `DERIVED` (классическое следствие подобия прямоугольных треугольников).
- **`Mathematical equivalence` (при прямом угле, однозначном соответствии $p \leftrightarrow a$, $q \leftrightarrow b$ и $p + q = c$):**
  - В совокупности `{a^2 = c*p, b^2 = c*q, p + q = c}` строго влечёт `a^2 + b^2 = c^2` ([`PTH-001`](./PTH-001.md)).
- **`Structural analogy` (НЕ доказательство):**
  - Изолированное уравнение `a^2 = c * p` структурно совпадает с любым средним геометрическим (в алгебре, физике $v^2 = 2as$ и т. д.).
